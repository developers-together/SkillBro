# Frontend Overview

SkillBro frontend is Vue SPA workspace page at `/skillbro`.

## Main files

- `resources/js/skillbro/main.ts`
- `resources/js/skillbro/SkillbroApp.vue`
- `resources/views/skillbro.blade.php`

## Scope in UI

Workspace covers all major domains:

- auth
- profile/instructor profile
- taxonomy
- courses/sections/lectures
- enrollment
- payments/refunds
- reviews
- quizzes
- notifications
- admin tools

## Design intent

This page behaves as integrated API console + demo shell for showcase.
